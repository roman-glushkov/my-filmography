# Моя фильмография

Локальное SPA на HTML, CSS и Vanilla JavaScript. Никакого бэкенда, npm или сторонних библиотек не требуется.

## Состав проекта

- `index.html` — разметка интерфейса.
- `style.css` — тёмная адаптивная тема.
- `script.js` — рендеринг, поиск, фильтры, сортировка, добавление/редактирование/удаление.
- `data.json` — импортированные записи из предоставленного ZIP-экспорта.
- `start-local-server.bat` — быстрый запуск локального статического сервера в Windows при наличии Python.

## Запуск

Поскольку JavaScript загружает внешний `data.json` с помощью `fetch()`, нельзя впервые открыть `index.html` двойным щелчком (`file://` блокирует такое чтение JSON в браузерах).

**Самый простой способ в Windows:** дважды щёлкните `start-local-server.bat`. Нужен установленный Python. Откроется `http://127.0.0.1:8000`.

**Альтернативно:** откройте папку проекта в VS Code и используйте расширение Live Server; либо запустите терминал в папке и выполните:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Откуда берутся данные

При первом запуске приложение читает `data.json`, импортирует 60 записей и сохраняет их в `localStorage` под ключом `my-filmography-v2`. В дальнейшем источником текущей коллекции становится `localStorage`, поэтому добавленные и отредактированные записи сохраняются между запусками.

Если вы вручную обновили `data.json` после первого запуска, изменения не заменят существующую коллекцию автоматически. Чтобы заново импортировать исходный JSON, удалите в инструментах разработчика браузера ключ `my-filmography-v2` для этого локального сайта, затем обновите страницу. Это удалит все текущие изменения, если предварительно не сохранить их отдельно.

## Что было в исходном экспорте

Импортировано 60 уникальных названий: 53 со статусом «Просмотрено» и 7 со статусом «Смотрю». Сохранены исходные типы, статусы, даты добавления и значения поля «Количество серий». «Марвел» сохранён отдельным типом «Вселенная».

В предоставленных CSV нет столбцов с комментариями, оценками, ссылками на постеры, отдельным прогрессом просмотра и франшизами. Эти поля оставлены пустыми, а не заполнены выдуманными значениями. Для дальнейшего использования в форму добавлено необязательное поле «Комментарий».
